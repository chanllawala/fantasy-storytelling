    The Research

    Dissertation for BSc (Hons) Computing Science, University of Stirling, April 2025. Supervised by Burcu Can Buglalilar.

    15 fantasy books, split 13 / 2 train / validation
    1,024 token chunks
    10 epochs, learning rate 1e-5
    ~14 h fine-tuning on Colab GPU
    23 participants, p < 0.01

    Problem

    Interactive fiction forces a trade-off: hand-built branching stories keep quality but do not scale; free-form LLM stories scale but forget characters, break world rules and drift from the genre. Fantasy, with its magic systems and invented geographies, exposes this "authorial paradox" most sharply.

    Approach

    The project compared GPT-3.5, base Mistral-7B-Instruct-v0.2, a Mistral model fine-tuned on a fantasy corpus, and GenreGPT-2, wrapped in a Flask web prototype with custom characters, three generated choices per turn, dynamic state tracking (character and world cards) and a four-dimension rating system.

    Architecture

    1. Browser UI (HTML, JS)
    2. Flask server (app.py)
    3. Story generator, prompt builder + parser
    4. LLM layer (GPT-3.5 API / local Mistral)
    5. State manager + CSV rating store

    Key findings

    • Mistral outputs were preferred over GPT-3.5 (4.2 vs 3.6 overall; 4.4 vs 3.3 for world-building).
    • Base Mistral had the highest lexical diversity (0.86); fine-tuning raised fantasy vocabulary but slightly narrowed breadth (0.83).
    • World-building was rated highest (3.87/5); character believability lowest (3.39/5), as consistency decays in long stories.
    • Local Mistral needed 1 to 2 minutes per segment, while the fine-tuned model took 10 to 15 s on a GPU but could not be deployed.

    Figures are reproduced from the dissertation. Interpretation of the p-value and user scores is the author's.

    Completing the Dissertation

    The report named limitations and future work it could not finish. This site delivers most of them as working software.

    About

    Tales Unwritten is the interactive companion to the dissertation Interactive Storytelling using Large Language Models by Kirtan Ajitbhai Chanllawala (student 3067560), University of Stirling, supervised by Burcu Can Buglalilar.

    It is a static site: plain HTML, CSS and JavaScript. There is no server, no build step and no dependency to install.

    Privacy and services

    • Story text goes to api.mistral.ai only when you supply a key.
    • Scene art is generated in your browser; nothing is sent anywhere for it.
    • Ratings and saved tales stay in your browser's local storage.
    • Fonts load from Google Fonts.
